# Abdur Rehman — Portfolio

Personal portfolio site built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Content

All personal content (bio, experience, skills, projects) lives in [`src/data/content.ts`](src/data/content.ts) — edit that file to update the site without touching component code.

Source assets (original CV, project screenshots, work samples) live in the project root under `projects/`, `work samples/`, and the top-level PDFs/images; optimized copies used by the site live under `public/`.
